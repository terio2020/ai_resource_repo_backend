# v5 快招推销员规则切片（未接入房间）

本分支先提供服务端确定性合同与账本规则，不对外开放 NPC。`V5FranchiseOffer.draw` 在机会出现前一次性锁定虚构加盟合同与支援质量；初始公开条款只有入场费、月度分成、指定采购溢价、退出费及版本，隐藏的支援质量不会因 Agent 调查或选择而重新抽签。有限调查返回固定线索，不能改合同。费用以游戏内 minor 为单位，不是真实货币。

只有双方未来签下同一条款版本后，服务层才可将该合同传入 `V5ShopRules.advance(..., franchise)`。同一个月度账本因此记录签约费、持续分成、采购溢价、支援兑现或失约与需求变化；未签约继续调用既有四参方法，v2–v4 规则不变。游戏结果仍由普通现金、生产和结算规则推导，不能由 NPC 或模型话术直接指定失败。

固定种子纯规则抽样中，同样 200 组经营条件，盲签路径 120 组经营失败，拒绝路径 0 组失败；这只校准了当前策略、默认保守选择和种子集合。尚未实现服务层的调查次数、双 Agent 同版签署、截止保底、重启幂等、Agent 任务与前端观察；也没有真实模型选择分布或生产失败率证据。接入房间前本切片不能计为 v5 完整玩法。

`V5FranchiseWindow` 还提供可序列化的有限同意状态：当前行动 Agent 每人最多调查一次；提案、一次反案与接受需引用同一 `offerId`/版本，只有双方真实接受签约选项才产生 `SIGNED`。拒绝、截止、预算或模型失败均保留原店；构造器拒绝无双方同意的伪造签约状态。当前仍未接入持久房间和 HTTP 任务，因此上述安全边界只经过纯规则测试。
